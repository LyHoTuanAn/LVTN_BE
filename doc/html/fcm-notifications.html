🔔 FCM & Push Notifications API

API endpoints để quản lý FCM Token và gửi Push Notifications.

📋 Mục Lục

  • Đăng ký FCM Token
  • Logout với FCM Token
  • Admin: Gửi thông báo đến một user
  • Admin: Gửi thông báo đến nhiều users
  • Admin: Broadcast đến tất cả users
  • Admin: Gửi đến topic cụ thể
  • Admin: Lấy danh sách topics
  • FCM Topics

📱 Đăng Ký FCM Token

URL: POST /api/auth/fcm-token

Method: POST

Authentication: Bắt buộc

Request Headers

Header Mô tả Ví dụ
X-Api-Key API key do server cấp your-api-key-here
Authorization Bearer token Bearer eyJ0eXAi...
Language Ngôn ngữ (en hoặc vi) vi

Request Body

Trường Bắt buộc Kiểu dữ liệu Mô tả
fcm_token ✓ String FCM token từ Firebase (100-500 ký tự)
device_type ✗ String Loại thiết bị: ios, android, web
device_id ✗ String ID duy nhất của thiết bị

Request Example

{
  "fcm_token": "dL8G2xK7qR5...",
  "device_type": "android",
  "device_id": "unique-device-id-123"
}

Response Success (200)

{
  "success": true,
  "code": "FCM_TOKEN_REGISTERED_SUCCESS",
  "message": "Đăng ký FCM token thành công",
  "data": {
    "fcm_token": "dL8G2xK7qR5...",
    "device_type": "android",
    "is_active": true
  }
}

🚪 Logout với FCM Token

URL: POST /api/auth/logout

Method: POST

Authentication: Bắt buộc

Request Body

Trường Bắt buộc Kiểu dữ liệu Mô tả
refresh_token ✗ String Refresh token để revoke
fcm_token ✗ String FCM token để xóa khỏi hệ thống

Request Example

{
  "refresh_token": "eyJ0eXAiOiJKV1QiLCJhbGci...",
  "fcm_token": "dL8G2xK7qR5..."
}

Response Success (200)

{
  "success": true,
  "code": "LOGOUT_SUCCESS",
  "message": "Đăng xuất thành công"
}

👤 Admin: Gửi Thông Báo Đến Một User

URL: POST /api/admin/notifications/send-to-user

Method: POST

Authentication: Bắt buộc (Admin)

Request Body

Trường Bắt buộc Kiểu dữ liệu Mô tả
user_id ✓ Integer ID của user cần gửi thông báo
title ✓ String Tiêu đề thông báo (max 255)
body ✓ String Nội dung thông báo (max 1000)
data ✗ Object Dữ liệu tùy chỉnh (sẽ được stringify)
image_url ✗ String URL hình ảnh đính kèm

Request Example

{
  "user_id": 123,
  "title": "Khuyến mãi đặc biệt",
  "body": "Giảm 50% cho tất cả các phim trong tuần này!",
  "data": {
    "type": "promotion",
    "promotion_id": "PROMO123"
  },
  "image_url": "https://example.com/promo.jpg"
}

Response Success (200)

{
  "success": true,
  "code": "NOTIFICATION_SENT_SUCCESS",
  "message": "Gửi thông báo thành công",
  "data": {
    "success": true,
    "message": "All notifications sent successfully",
    "sent_count": 2,
    "failed_count": 0,
    "failed_tokens": []
  }
}

📢 Admin: Broadcast Đến Tất Cả Users

URL: POST /api/admin/notifications/send-to-all

Method: POST

Authentication: Bắt buộc (Admin)

📡 Topic Messaging

API này sử dụng FCM Topic Messaging để gửi thông báo đến tất cả users đã đăng ký topic celes_all_users. Đây là cách hiệu quả nhất để gửi broadcast vì chỉ cần 1 request duy nhất.

Request Body

Trường Bắt buộc Kiểu dữ liệu Mô tả
title ✓ String Tiêu đề thông báo (max 255)
body ✓ String Nội dung thông báo (max 1000)
data ✗ Object Dữ liệu tùy chỉnh
image_url ✗ String URL hình ảnh đính kèm

Response Success (200)

{
  "success": true,
  "code": "NOTIFICATION_BROADCAST_SUCCESS",
  "message": "Đã gửi thông báo đến tất cả người dùng",
  "data": {
    "success": true,
    "message": "Notification sent to topic successfully",
    "topic": "celes_all_users"
  }
}

📋 Admin: Lấy Danh Sách Topics

URL: GET /api/admin/notifications/topics

Method: GET

Authentication: Bắt buộc (Admin)

Response Success (200)

{

  "code": "TOPICS_FETCHED_SUCCESS",
  "data": {
    "topics": {
      "all_users": "celes_all_users",

      "promotions": "Promotions and discounts",
      "booking_reminders": "Booking reminder notifications"

  }
}

📡 FCM Topics

Danh sách các topics có sẵn trong hệ thống:

Topic Key Topic Name Mô tả
all_users celes_all_users Tất cả users - dùng cho broadcast
new_movies celes_new_movies Thông báo phim mới
promotions celes_promotions Khuyến mãi và giảm giá
booking_reminders celes_booking_reminders Nhắc nhở lịch chiếu

⚠️ Error Codes

Code HTTP Status Mô tả
FCM_TOKEN_REGISTRATION_FAILED 500 Đăng ký FCM token thất bại
FCM_TOKEN_NOT_FOUND 404 Không tìm thấy FCM token
NOTIFICATION_SEND_FAILED 400 Gửi thông báo thất bại
NOTIFICATION_USER_NOT_FOUND 404 Không tìm thấy user
NOTIFICATION_NO_TOKENS 400 User không có FCM token nào
VALIDATION_ERROR 422 Dữ liệu đầu vào không hợp lệ
UNAUTHORIZED 401 Chưa đăng nhập
FORBIDDEN 403 Không có quyền truy cập

ℹ️ Notes

  • FCM Token API yêu cầu authentication (Bearer token)
  • Admin Notification APIs yêu cầu admin role
  • Khi logout, nên gửi kèm fcm_token để xóa khỏi hệ thống
  • Client cần subscribe vào topic celes_all_users sau khi đăng nhập để nhận broadcast
  • Tất cả data values trong notification sẽ được stringify (FCM requirement)

⚠️ Flutter Integration

Để nhận broadcast notifications, Flutter app cần:

  1. Subscribe vào topic celes_all_users sau khi đăng nhập
  2. Unsubscribe khỏi topics trước khi logout
  3. Gửi FCM token mới khi token refresh
// Subscribe after login
FirebaseMessaging.instance.subscribeToTopic('celes_all_users');

// Unsubscribe before logout
FirebaseMessaging.instance.unsubscribeFromTopic('celes_all_users');
