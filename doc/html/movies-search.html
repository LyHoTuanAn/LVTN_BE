🔍 Movies Search API

API tìm kiếm phim với nhiều bộ lọc nâng cao. Hỗ trợ tìm kiếm theo từ khóa, thể loại, trạng thái, phân loại độ tuổi, thời lượng, và năm phát hành.

Headers bắt buộc:
X-Api-Key: API key do server cấp
Language: en hoặc vi (mặc định: en)

⚡ Public Route: API này không yêu cầu authentication

Tìm kiếm phim

GET /api/movies/search

Query Parameters

Tham sốKiểuBắt buộcMô tả
keywordstringKhôngTừ khóa tìm kiếm (tìm trong title và description)
genrestringKhôngThể loại phim (Action, Comedy, Drama, Horror, Romance, Sci-Fi, Animation, ...)
statusstringKhôngTrạng thái phim: COMING_SOON, UPCOMING, NOW_SHOWING
age_classificationstringKhôngPhân loại độ tuổi: P, K, T13, T16, T18, C
duration_minintegerKhôngThời lượng tối thiểu (phút)
duration_maxintegerKhôngThời lượng tối đa (phút)
release_yearintegerKhôngNăm phát hành
sort_bystringKhôngSắp xếp theo: title, release_date, duration, created_at. Mặc định: release_date
sort_orderstringKhôngThứ tự sắp xếp: asc, desc. Mặc định: desc
per_pageintegerKhôngSố phim mỗi trang. Mặc định: 15
pageintegerKhôngTrang hiện tại. Mặc định: 1

Giải thích các giá trị

Status (Trạng thái phim)

Giá trịMô tả
COMING_SOONSắp ra mắt - Chưa có suất chiếu
UPCOMINGSắp chiếu - Có suất chiếu trong tương lai (sau hôm nay)
NOW_SHOWINGĐang chiếu - Có suất đang diễn ra hoặc còn suất trong hôm nay

Age Classification (Phân loại độ tuổi)

Giá trịMô tả
PMọi lứa tuổi (All Ages)
KTrẻ em (cần có phụ huynh hướng dẫn)
T13Từ 13 tuổi trở lên
T16Từ 16 tuổi trở lên
T18Từ 18 tuổi trở lên
CPhim cấm

Ví dụ Request

// Tìm kiếm theo từ khóa
GET /api/movies/search?keyword=avengers

// Tìm phim đang chiếu + thể loại Action
GET /api/movies/search?status=NOW_SHOWING&genre=Action

// Tìm phim phù hợp cho trẻ em, thời lượng dưới 120 phút
GET /api/movies/search?age_classification=P&duration_max=120&sort_by=title&sort_order=asc

// Tìm phim ra mắt năm 2024
GET /api/movies/search?release_year=2024&per_page=20

// Kết hợp nhiều bộ lọc
GET /api/movies/search?keyword=marvel&genre=Action&status=NOW_SHOWING&age_classification=T13&duration_min=90&duration_max=180&release_year=2024&sort_by=release_date&sort_order=desc&per_page=10

Lưu ý

  • Tìm kiếm keyword: Tìm kiếm không phân biệt hoa thường, hỗ trợ tìm kiếm một phần của từ
  • Status filter: Lọc theo trạng thái được tính toán dựa trên suất chiếu (showtimes), không phải giá trị cố định trong database
  • Phân trang: API trả về thông tin phân trang trong meta và links
  • Sắp xếp mặc định: Theo ngày phát hành giảm dần (phim mới nhất trước)
  • is_favorited: Chỉ trả về true nếu user đã đăng nhập và đã thêm phim vào yêu thích
