🏠 Home API

API endpoint để lấy dữ liệu cho màn hình home của mobile app.

📋 Thông Tin Endpoint

URL: GET /api/home

Method: GET

Authentication: Không cần

📤 Headers

Bắt buộc ✓

Header Mô tả Ví dụ
X-Api-Key API key do server cấp your-api-key-here
Language Ngôn ngữ (en hoặc vi) vi hoặc en
Accept Content type chấp nhận application/json

🔍 Query Parameters

Trường Bắt buộc Kiểu dữ liệu Mô tả Mặc định
coming_soon_limit ✗ Number Số lượng phim sắp chiếu 10
room_limit ✗ Number Số lượng phòng chiếu 10
showtime_limit ✗ Number Số lượng suất chiếu sắp tới 10
news_limit ✗ Number Số lượng tin tức 10

✅ Response Success

{
  "success": true,
  "code": "HOME_DATA_FETCHED_SUCCESS",
  "message": "Home data fetched successfully",
  "data": {
    "coming_soon": [...],
    "rooms": [...],
    "upcoming_showtimes": [...],
    "news": [...]
  }
}

📊 Response Fields

Main Response

Trường Bắt buộc Kiểu dữ liệu Mô tả
success ✓ Boolean Trạng thái thành công (true)
code ✓ String Mã response (HOME_DATA_FETCHED_SUCCESS)
message ✓ String Thông báo theo ngôn ngữ client yêu cầu
data ✓ Object Dữ liệu trang chủ
data.coming_soon ✓ Array Danh sách phim sắp chiếu
data.rooms ✓ Array Danh sách phòng chiếu
data.upcoming_showtimes ✓ Array Danh sách suất chiếu sắp tới (7 ngày tới)
data.news ✓ Array Danh sách tin tức đã xuất bản

❌ Response Error

Validation Error

{
  "success": false,
  "code": "VALIDATION_ERROR",
  "message": "Dữ liệu không hợp lệ",
  "errors": {
    "banner_limit": "The banner limit must be between 1 and 20."
  }
}

📝 Success Codes

Code HTTP Status Mô tả
HOME_DATA_FETCHED_SUCCESS 200 Lấy dữ liệu trang chủ thành công

⚠️ Error Codes

Code HTTP Status Mô tả
VALIDATION_ERROR 422 Dữ liệu validation không hợp lệ
INVALID_API_KEY 401 API key không hợp lệ
INTERNAL_SERVER_ERROR 500 Lỗi server

📮 Postman Example

Request

GET {{base_url}}/api/home?coming_soon_limit=10&room_limit=10&showtime_limit=10&news_limit=10

Headers:
  X-Api-Key: {{api_key}}
  Language: vi
  Accept: application/json

ℹ️ Notes

  • API này là public route, không cần authentication
  • Upcoming showtimes chỉ lấy suất chiếu trong 7 ngày tới và không bao gồm suất chiếu đã hủy
  • News chỉ lấy tin tức có status = 'published'
  • Dữ liệu được sắp xếp theo:
    • Coming soon: release_date ASC (sắp chiếu trước)
    • Rooms: name ASC (theo tên)
    • Showtimes: date ASC, start_time ASC (ngày và giờ sớm nhất trước)
    • News: created_at DESC (mới nhất trước)
  • News title, summary, content sẽ được trả về theo ngôn ngữ client yêu cầu (vi hoặc en) dựa vào header Language
  • Tất cả dữ liệu trả về đã được format qua API Resources
